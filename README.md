# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING


## AIM:
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Create a New Sketch:            

   Open autodesk fusion 360 on your computer. From the Design workspace, select the Create Sketch option from the toolbar. The sketch environment will open with the available construction planes. 

  <img width="242" height="283" alt="image" src="https://github.com/user-attachments/assets/ac19b54a-ee96-429c-95f6-72d920912a56" />

2. Select the Sketching Plane:   
    
   Select the appropriate plane (XY, XZ, or YZ) according to the given drawing and project requirements. The selected plane will become the working surface for creating the sketch.          

3. Create the Basic Geometry:               

    Use the sketching tools available in Fusion 360 to draw the required geometry. Tools such as (Line, Circle, Arc, Rectangle, Polygon, and Point) can be used to construct the given sketch. 

 4.Create the Main Body Using Extrude:
         
   Finish the sketch and select the Extrude command. Extrude the rectangular profile to create the three-dimensional camera body. Use the indicated depth of 50 mm from the side view as the overall depth reference. Check the orientation of the body before proceeding.

5. Draw the Front Circular Feature:

     Select the front face of the camera body and create a new sketch. Choose the Circle tool and draw a circle with a diameter of 50 mm (Ø50). This circular feature represents the main camera lens housing shown in the front view.
   
6. Position the Circular Feature:

      Use the Dimension tool to position the centre of the Ø50 mm circle accurately. Locate the centre 50 mm from the left reference edge and 30 mm from the bottom reference edge, following the dimensions shown in the drawing. Ensure that the circle is properly aligned with the horizontal and vertical centre lines.
   
7. Create the Lens Housing:

    Finish the sketch and use the Extrude command to form the circular lens housing. Apply the required extrusion distance according to the isometric representation. If the lens is intended to be recessed, use the Cut option instead. Keep the circular feature concentric with the original Ø50 mm profile.
   
8. Construct the Raised Upper Section:

    Select the top face of the main camera body and create a sketch for the raised rectangular section. Draw the stepped profile according to the top and isometric views. Use the available drawing dimensions to position the raised section and maintain the correct alignment with the main body.

9. Create the Small Rectangular Top Feature:

   On the left side of the upper surface, draw a small square-shaped profile using the Rectangle tool. The exact dimensions of this square are not specified in the drawing, so estimate its size from the given view or use the dimensions provided by your instructor. Finish the sketch and extrude it slightly upward to create the raised rectangular feature.
    
10. Create the Upper Cylindrical Feature:

    Select the raised upper section and start a new sketch. Draw a circle of diameter 20 mm (Ø20) on the top surface, as indicated in the lower-left orthographic view. Position the circle according to the drawing and use the Extrude command to create the cylindrical projection on the top of the camera.
    
11. Construct the Rear Projection:

    Refer to the side view and create the rectangular projection extending from the rear of the camera body. Sketch the appropriate rectangular profile on the selected face and use Extrude to form the projection. Maintain the overall dimensions shown in the drawing and ensure that the rear section is aligned correctly with the main body.
    
12. Create the Lower Rectangular Projection:

     Refer to the lower-left orthographic view and construct the rectangular projection below the main body. Use the dimension of 30 mm shown in the drawing as the relevant vertical reference. Position the feature carefully using the Dimension tool and create the required solid geometry using Extrude.
    
13. Apply the Horizontal and Vertical References:

       Use the horizontal dimension of 85 mm shown in the lower-left view to locate the corresponding features. Apply the vertical reference dimensions of 30 mm and 35 mm to position the lower projection and circular feature as indicated. These dimensions should be interpreted according to their extension lines in the original drawing.10. Dimension check:  Check the sketch against the dimensions shown, including 178.77 mm, 140 mm,, R20, Ø20.  

<img width="269" height="352" alt="image" src="https://github.com/user-attachments/assets/5d5fbfdb-b558-43b1-b6ad-d3c22bcbdc7f" />

14. Add Centre Lines and Check Alignment:


    Add centre lines to the circular features to indicate their axes. Check the front, top and side views to confirm that the Ø50 mm lens and Ø20 mm cylindrical feature are correctly positioned. Verify that the stepped body and projections match the isometric representation.
    
15. Finish the Sketch:  

       Check the final drawing for correct geometry, dimensions, view arrangement, and ISO standard representation, select Finish Sketch. Make any necessary corrections before finalizing the drawing. This exits the sketching environment and saves the completed 2D sketch within the Fusion 360 design.

16. Save the Final Project:  

      Check the completed 2D sketch against the given reference drawing. Save the Fusion 360 design with an appropriate project name. Ensure that the dimensions, symmetrical profile and central cutout match the required design . Save the completed Fusion 360 design and drawing 
file with the appropriate project name.
